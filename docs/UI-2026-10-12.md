## Persian composition

The InDesign example is a technique reference, not literal font-independent values. The actual Rokh font is measured after loading. A paragraph composer optimizes line breaks across the whole paragraph, permits word spaces between 0.55 and 2.0 times the font's natural space, and heavily prioritizes fully filled non-final lines. This avoids unlimited native justification, kashida/tatweel, glyph scaling and letter tracking. The body leading is 1.45; existing denser wide/deck rules still apply where needed to fit a panel.

Every source character, joiner, inline emphasis and link is preserved. The final line ranges right. A line is allowed a natural ending only when the permitted word-space interval cannot fill it without breaking the constraints. The desktop history sample fills every non-final line. This is browser-measured bounded composition, not a claim to reproduce Adobe's exact World-Ready Composer. No word-space 50/70/90 values from another font were blindly copied.

Composition is progressive, near-viewport, font-aware and resize-aware. English text is unchanged. No runtime design library or generated image was added.
