## نتیجهٔ بازتأیید

- فارسی: هر ۹۸ محصول یکتا تأیید شد؛ API رسمی ۹۹ پست دارد، زیرا T Rex دو پست دارد.
- انگلیسی: هر ۹۷ محصول یکتا تأیید شد. مجموع دو زبان ۹۹ سنگ و ۱۹۵ رکورد زبانی است.
- در مرحلهٔ تکمیلی، هر ۱۲۴ رکورد زبانیِ باقی‌مانده بازتأیید شد؛ هیچ مشخصات قدیمیِ تأییدنشده باقی نمانده است.
- API هر دو زبان دوباره دریافت شد؛ شناسه‌ها، نام‌ها، دسته‌های API، رنگ‌ها و مراجع تصویر نسبت به snapshot قبلی تغییر نکرده‌اند.
- نوع و کشور مبدأ از متن خودِ صفحه، دسته از مسیر رسمی صفحه، و نام و رنگ‌های اعلام‌شده از API رسمی هر زبان گرفته شده‌اند.
- عضویت فیلتر دسته از API است؛ اگر در API خالی باشد، فقط دستهٔ واقعاً منتشرشده در breadcrumb خودِ محصول استفاده می‌شود، نه حدس از کشور یا عکس.
- شواهد هر صفحه شامل URL، عنوان، نوع، کشور، مراجع عکس اصلی و SHA-256 پاسخ HTML در `products/data/official-source.json` ثبت است.

## اختلاف‌های اصلاح‌شده نسبت به نسخهٔ قبلی کاتالوگ

138 فیلد در 45 محصول تغییر کرد:

- متن نوع سنگ: 10 رکورد زبانی؛ عمدتاً متن انگلیسیِ واقعاً نمایش‌داده‌شده در سایت فارسی، به‌جای ترجمهٔ قبلی.
- دستهٔ نمایان: 51 رکورد زبانی؛ اطلاعاتی که در API خالی بود ولی در مسیر صفحهٔ اصلی منتشر شده است.
- عضویت فیلتر داخلی/وارداتی: 77 رکورد زبانی؛ فقط با اتکا به breadcrumb واقعی.
- کشور مبدأِ قبلی با صفحات رسمی مطابقت داشت؛ با این حال منشأ همهٔ آن‌ها اکنون بازتأیید شده است.

فهرست کامل قبل/بعد و لینک منبع: `PRODUCT-RECONCILIATION-2026-10-12.csv` و `.json`.

## تفاوت‌های خود سایت و قواعد حفظ منبع

- نوع نمایان و taxonomy فیلتر با هم یکسان فرض نشده‌اند؛ تناقض داخلی منبع بدون اصلاح علمیِ حدسی حفظ می‌شود.
- دستهٔ Elegant Brown در فارسی «وارداتی» و در انگلیسی «Domestic» است؛ هر نسخه مطابق منبع همان زبان است، نه استنباط از Brazil.
- رنگ از عکس یا نام حدس زده نمی‌شود؛ فقط رنگ‌های اعلام‌شده در API وارد می‌شوند.
- River Blanche و محتوای تحریریهٔ معدن در فهرست تجاری پنهان‌اند. Black Fantasy نام قبلی Black Tempest است.
- River Stone فقط در انگلیسی؛ Cristallo Rosa و Mozzarella فقط در فارسی نمایش داده می‌شوند.
- اختلاف نام فایل عکس با اختلاف عکس یکی نیست: عکس‌های Patagonia Pink، Kojin و Elegant Brown که نام متفاوتی در منبع دارند، با فایل‌های موجود مقایسه شدند و تصویر یکسان بود. گونه‌های `-scaled` و ابعاد thumbnail نیز جدا از تغییر محصول بررسی شدند.
