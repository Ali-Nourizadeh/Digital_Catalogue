# تطبیق با منبع رسمی — ۲۰۲۶/۱۰/۱۲

- API رسمی فارسی: https://fa.behkooshan.ir/wp-json/wc/store/v1/products?per_page=100
- API رسمی انگلیسی: https://behkooshan.ir/wp-json/wc/store/v1/products?per_page=100
- فارسی: ۹۹ پست، ۹۸ محصول یکتا (T Rex دو پست دارد). انگلیسی: ۹۷ محصول یکتا. مجموع دو زبان: ۹۹ سنگ.
- نام، رنگ‌های اعلام‌شده و عضویت فیلترها از API هر زبان است؛ رنگ از عکس یا اسم حدس زده نمی‌شود. دستهٔ خالی با داخلی/وارداتی یا معدن پر نمی‌شود.
- مشخصات نمایان «نوع» و «مبدأ» با taxonomy فیلتر یکسان فرض نمی‌شوند: در موارد تعارض، هرکدام از جایگاه واقعی خود در سایت رسمی استفاده می‌کند.
- بازخوانی موفق صفحات مشخصات در این نوبت: فارسی ۵۷/۹۸ و انگلیسی ۱۴/۹۷. ۱۲۴ رکورد زبانی هنوز بازتأیید صفحهٔ کامل نشده‌اند. محدودیت دسترسی/نرخ درخواست منبع مانع تکمیل شد.
- مبدأِ بازتأییدنشده از آرشیو ثبت‌شدهٔ رسمی ۲۰۲۶/۰۹/۲۴ است، با هشدار تاریخ در صفحهٔ محصول. این گزارش ادعای تأیید صددرصدی امروز ندارد.
- منبع و منشأ هر فیلد در `products/data/official-source.json` ثبت شده و هر صفحه به URL اصلی خود لینک می‌دهد.
- River Blanche و محتوای تحریریهٔ معدن در فهرست تجاری پنهان‌اند؛ Black Fantasy نام قبلی Black Tempest است. River Stone فقط در انگلیسی؛ Cristallo Rosa و Mozzarella فقط در فارسی نمایش داده می‌شوند.

## اصلاح ظاهر

- هیچ سطر میانی کوتاه به‌صورت دستی تحمیل نمی‌شود؛ در صورت عدم امکان ترکیب محدود، کل پاراگراف به چیدمان بومی مرورگر برمی‌گردد.
- خطوط ترکیب‌شده دوباره نمی‌شکنند؛ اگر از عرض واقعی خارج شوند، به پاراگراف اصلی برمی‌گردند. متن و نشانه‌ها حفظ می‌شوند؛ کشیده، تغییر مقیاس حروف و tracking افزوده نمی‌شود.
- فاصلهٔ اضافی ردیف فیلتر روی لمس حذف شده؛ ارتفاع قابل لمس ۴۴ پیکسل و ظاهر دکمه ۳۲ پیکسل حفظ می‌شود. دسکتاپ فاصلهٔ ۶ پیکسل دارد.
- آزمون: عرض‌های ۳۹۰، ۴۸۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰؛ بررسی سه بخش گزارش‌شده و فیلترها، بدون overflow. ۳۹۶ صفحهٔ جزئیات با snapshot منبع بررسی می‌شوند؛ این آزمون جای بازتأیید آنلاین را نمی‌گیرد.
