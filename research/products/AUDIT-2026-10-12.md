# Product audit — 2026-10-12

## Outcome and scope

The current public product inventories have **99 Persian posts and 97 English posts**, mapping to **99 distinct catalogue products**. The Persian list contains two T Rex / T.Rex posts for the same stone. Two stones are Persian-only (Cristallo Rosa and Mozzarella); River Stone is English-only. No published product in either current inventory is missing from the catalogue. The generated catalogue contains those 99 products plus a separate quarry entry (100 records, not 100 distinct commercial products).

This is an inventory and structured-data audit, not a new certification of technical stone properties. API attributes are not always the same as the visible product-page labels, and the two language sites do not always agree. Existing provenance decisions were preserved rather than overwriting them with hidden attributes.

## Sources and method

Read the public WordPress product indexes and WooCommerce Store API on both official hosts, using gzip-compressed responses. The English index returned X-WP-Total: 97 and X-WP-TotalPages: 1; the Store API independently returned the same 97 IDs. The Persian index and Store API independently returned the same 99 IDs. Records were matched using recorded source post IDs and URLs, not approximate names. All 196 source records map to catalogue entries; their union was independently checked against the 99 non-quarry generated records.

- https://behkooshan.ir/wp-json/wp/v2/product?per_page=100
- https://fa.behkooshan.ir/wp-json/wp/v2/product?per_page=100
- https://behkooshan.ir/wp-json/wc/store/v1/products?per_page=100
- https://fa.behkooshan.ir/wp-json/wc/store/v1/products?per_page=100
- https://behkooshan.ir/products/
- https://behkooshan.ir/product/black-diamond/

The CSV beside this report records every matched post. Empty type/colour cells mean the source omitted that attribute, not that a product has no type or colour. IDs are identifiers, not additive quantities. Duplicate catalogue slugs across languages, and the Persian T Rex duplicate, are expected.

## Images, downloads and local completeness

The Store APIs contain 198 gallery-image references. 195 match recorded original filenames (normalizing WordPress scaled/size suffixes). Patagonia Pink's differently named Persian listing image was downloaded and compared with the stored Absolute-Black-p-1.jpg: RGB mean absolute difference at 96×96 is 0.0, confirming it is already present under another filename.

Two remaining filenames could not be re-downloaded within the request time limit:

- Elegant Brown: https://fa.behkooshan.ir/wp-content/uploads/Elegant-Brown.jpg (stored main file: Elegant-Brown-1.jpg).
- Kojin: https://fa.behkooshan.ir/wp-content/uploads/nehbandan1-1.jpg (the existing source notes record it as an identical re-upload of nehbandan1.jpg).

These two current binary references remain **unverified in this audit**; no new image was invented and no existing image was replaced on filename evidence alone. Full live project galleries and every original texture endpoint were not re-downloaded. Local presence was checked for every generated photo width, every texture reference, and every product route in both languages and readings: **zero missing local files**. Local file existence is not a claim that every live source download URL still works.

## UI changes and validation

Toolbar chips are 32 px high on desktop (formerly 44 px). Filter choices and their legends are 32 px (formerly 40 px). Devices with coarse pointers keep 44 px interactive targets. Font size, focus states, selected states, language links and view links are preserved.

Persian quarry prose uses natural start/RTL alignment, zero letter tracking, normal word spacing, pretty wrapping and 1.55 leading. English alignment is unchanged. Full two-sided justification is deliberately not used for Persian: it necessarily expands word spaces or glyphs, contrary to the requirement to avoid white gaps and kashida.

Visual previews inspected: Persian desktop/mobile catalogue history, desktop/mobile product filters, sideways Persian history, and the English mobile toolbar. Automated checks passed for eight listing/catalogue routes on desktop and touch-mobile (16 checks): computed control heights 32 / 44 px, natural RTL text spacing, no horizontal viewport overflow and no browser exceptions. These are representative shared-style routes; this does not claim that every one of the 400 individual product pages was visually inspected.

## Publication

Edit the product stylesheet on Behkooshan-products, not the generated products/ copy in Behkooshan-catalogue. Its existing publish workflow copies the product site into that folder after merge. The catalogue's shared stylesheet is edited separately on Behkooshan-catalogue. Neither source workflow was changed.
