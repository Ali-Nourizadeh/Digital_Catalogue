# release — کاتالوگ دیجیتال به‌کوشان

این بسته فقط شامل نسخهٔ به‌روز آمادهٔ انتشار و راهنماهای نصب است؛ سورس پروژه داخل آن نیست. سایت با HTML، CSS و JavaScript ساخته شده و برای اجرا روی سرور به Node.js یا دیتابیس نیاز ندارد.

## هر چیز کجاست؟

```text
release/
├── README.md                  همین راهنمای ساده
├── site/                      فایل‌های آمادهٔ انتشار سایت
│   ├── index.html             کاتالوگ فارسی
│   ├── en/                    کاتالوگ انگلیسی
│   ├── wide/                  کاتالوگ افقی، فارسی و انگلیسی
│   ├── products/              فهرست و جزئیات محصولات، هر دو زبان و نما
│   │   ├── assets/            استایل، کد، فونت و آیکون محصولات
│   │   ├── media/             عکس‌های محصولات
│   │   └── research/          فایل‌های بافت برای دانلود؛ حذف نکنید
│   ├── assets/                استایل، کد، فونت و لوگوی کاتالوگ
│   └── media/                 تصاویر کاتالوگ
├── deploy/                    نمونهٔ تنظیم Nginx یا Caddy
├── docs/IT-HANDOFF.fa.md       راهنمای فنی نصب، تست و بازگشت به نسخه قبلی
├── release-manifest.json      شناسهٔ نسخه و مشخصات فایل‌های سایت
├── SHA256SUMS.txt              هش فایل‌ها برای بررسی سلامت بسته
└── LICENSE                    مجوز کد پروژه
```

## چطور روی سرور شرکت دیپلوی کنیم؟

۱. یک آدرس مثل `catalogue.company.ir` تعیین کنید و دامنه و HTTPS آن را تنظیم کنید.

۲. **فقط پوشهٔ `site/` را منتشر کنید.** document root وب‌سرور باید داخل همین پوشه باشد؛ نه کل پوشهٔ `release/`. صفحهٔ پیش‌فرض `index.html` است.

۳. برای Nginx، نمونهٔ `deploy/nginx.conf.example` را با دامنه و مسیر واقعی شرکت تطبیق دهید، تنظیمات را تست و سپس سرویس را reload کنید. برای Caddy، فایل نمونهٔ همان وب‌سرور موجود است؛ فقط یکی از این وب‌سرورها کافی است. در Windows/IIS نیز `site/` به‌عنوان سایت استاتیک، با MIME صحیح و HTTPS تنظیم شود.

در نمونهٔ Nginx، مسیر `/var/www/behkooshan/current/site` فرض شده است. اگر مسیر نصب فرق دارد، آن را عوض کنید. **نمونهٔ Nginx به‌تنهایی HTTPS را فعال نمی‌کند**؛ IT باید گواهی یا reverse proxy شرکت را تنظیم کند. وب‌سرور فقط مجوز خواندن لازم دارد.

## بعد از نصب چه چیزی را تست کنیم؟

- `/` و `/en/`: کاتالوگ؛ `/wide/` و `/wide/en/`: کاتالوگ افقی.
- `/products/` و `/products/en/`: محصولات؛ `/products/wide/` و `/products/wide/en/`: محصولات افقی.
- جست‌وجو، فیلترها، برگشت، تصاویر، دانلود بافت و ظاهر موبایل/دسکتاپ.
- بدون فیلتر، هر چهار فهرست محصولات باید ۹۹ سنگ نشان دهند.

برای دیدن سایت روی دستگاه خودتان، داخل پوشهٔ `release` اجرا کنید:

```bash
python3 -m http.server 8000 --directory site
```

سپس `http://localhost:8000` را باز کنید. این فقط پیش‌نمایش محلی است، نه روش استقرار نهایی شرکت.

## به‌روزرسانی

نسخهٔ تازهٔ `release.zip` را از مسئول پروژه بگیرید. قبل از جایگزینی `site/`، نسخهٔ قبلی را برای بازگشت نگه دارید و نسخهٔ جدید را روی آدرس آزمایشی تست کنید. سورس و ابزارهای ساخت در ریپو نگهداری می‌شوند و جزو بستهٔ تحویل به سرور نیستند.

برای بررسی سلامت بسته در Linux، داخل `release/` اجرا کنید:

```bash
sha256sum -c SHA256SUMS.txt
```

## مهم، قبل از انتشار عمومی

طبق راهنمای پروژه، فونت لاتین TT Firs Neue موجود نسخهٔ Trial است. مالک پروژه باید پیش از انتشار شرکتی، مجوز وب تجاری را تهیه و فایل مجاز را جایگزین کند یا جایگزین مجاز دیگری را تأیید کند. `LICENSE` کد، مجوز فونت یا تصاویر را تأمین نمی‌کند. این بسته از نظر فنی آمادهٔ نصب است؛ وضعیت مجوز فونت باید پیش از انتشار عمومی نهایی شود.
