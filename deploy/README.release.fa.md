# کاتالوگ دیجیتال به‌کوشان — release

نسخهٔ آمادهٔ انتشار کاتالوگ و محصولات، در یک سایت و زیر یک دامنه. سورس توسعه، داده‌های ساخت و ابزارهای پروژه در این بسته نیستند. سایت استاتیک است؛ اجرای آن به Node.js، دیتابیس یا نصب پکیج نیاز ندارد.

## داخل بسته

```text
release/
├── site/                    سایت آمادهٔ انتشار: کاتالوگ و محصولات
│   ├── index.html           صفحهٔ اصلی کاتالوگ
│   ├── en/                  کاتالوگ انگلیسی
│   ├── wide/                کاتالوگ افقی، فارسی و انگلیسی
│   ├── products/            فهرست محصولات، جزئیات و فایل‌های دانلود
│   ├── assets/              استایل‌ها، اسکریپت‌ها، فونت‌ها و آیکون‌ها
│   └── media/               تصاویر کاتالوگ
├── deploy/                  نمونهٔ تنظیمات Nginx و Caddy
├── docs/DEPLOYMENT.fa.md     راهنمای فنی نصب، به‌روزرسانی و بازگشت
├── README.md                این راهنما
├── LICENSE                  حقوق کد و مستندات اصلی پروژه
├── THIRD-PARTY-NOTICES.md    توضیح مجوز اجزای شخص ثالث
├── release-manifest.json    شناسهٔ نسخه و مشخصات بسته
└── SHA256SUMS.txt           اطلاعات بررسی سلامت فایل‌ها
```

پوشهٔ `site/products/research/` شامل بافت‌های قابل دانلود است و بخشی از سایت محسوب می‌شود؛ حذف آن لینک‌های دانلود را خراب می‌کند.

## انتشار روی سرور

**فقط `site/` ریشهٔ وب‌سایت است**؛ نه پوشهٔ `release/`. کاتالوگ و محصولات با همین یک نصب اجرا می‌شوند و سرور یا تنظیم جداگانه‌ای لازم ندارند.

1. فایل `release.zip` در مسیر نصب از حالت فشرده خارج می‌شود.
2. ریشهٔ وب‌سرور (Document Root) روی مسیر کامل پوشهٔ `release/site/` و صفحهٔ پیش‌فرض روی `index.html` قرار می‌گیرد.
3. دامنه و HTTPS طبق تنظیمات سرور فعال می‌شوند. نمونه‌های `deploy/` برای Nginx و Caddy نقطهٔ شروع هستند؛ نام دامنه و مسیر نصب آن‌ها باید با محیط واقعی مطابقت داشته باشد. در IIS نیز همین پوشه به‌صورت سایت استاتیک منتشر می‌شود.
4. پس از نصب، صفحات، تصاویر، فیلترها و دانلود بافت بررسی می‌شوند.

نمونهٔ Nginx فقط HTTP دارد؛ HTTPS به گواهی و تنظیم TLS روی وب‌سرور یا پراکسی نیاز دارد. برای نصب ساده‌تر، یک زیردامنهٔ اختصاصی مانند `catalogue.company.ir` پیشنهاد می‌شود. جزئیات نصب در `docs/DEPLOYMENT.fa.md` آمده است.

## آدرس‌های سایت

| بخش | فارسی | انگلیسی |
| --- | --- | --- |
| کاتالوگ عمودی | `/` | `/en/` |
| کاتالوگ افقی | `/wide/` | `/wide/en/` |
| محصولات عمودی | `/products/` | `/products/en/` |
| محصولات افقی | `/products/wide/` | `/products/wide/en/` |

بدون فیلتر، هر چهار فهرست محصولات ۹۹ سنگ دارند. جابه‌جایی بین کاتالوگ و محصولات از داخل سایت انجام می‌شود.

## پیش‌نمایش و به‌روزرسانی

پیش‌نمایش محلی، در صورت نصب Python و از داخل پوشهٔ `release/`:

```bash
python3 -m http.server 8000 --directory site
```

آدرس پیش‌نمایش `http://localhost:8000` است؛ این روش برای سرور نهایی پیشنهاد نمی‌شود. در به‌روزرسانی، نسخهٔ جدید ابتدا آزمایش و نسخهٔ قبلی برای بازگشت نگهداری می‌شود. بررسی سلامت فایل‌ها در Linux: `sha256sum -c SHA256SUMS.txt`.
